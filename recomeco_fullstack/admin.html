Conta autenticada

Ative o acesso administrativo

Depois de criar e confirmar sua conta, o proprietário do projeto precisa promovê-la no SQL Editor do Supabase. Troque o e-mail de exemplo pelo e-mail exato usado no cadastro:

insert into public.admin_users (user_id)
select id from auth.users
where lower(email) = lower('seu-email@exemplo.com')
on conflict (user_id) do nothing;

Execute esse comando apenas para uma conta de confiança. Depois, saia e entre novamente nesta página.
